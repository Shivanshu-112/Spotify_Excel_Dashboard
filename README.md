# 🎵 Spotify Popularity & Genre Analysis

## 📌 About The Project

This project is a **Spotify music data analysis and visualization project** that I created to understand how different music genres perform in terms of **popularity, playtime, and explicit content**.

I worked with a dataset containing Spotify track information and analyzed it using **Microsoft Excel**, including Pivot Tables and Dashboard-based visualizations.

The main purpose of this project is to find useful patterns and insights from Spotify music data.

---

## 🎯 Objectives

Through this project, I aimed to:

* Analyze music based on different genres.
* Compare the popularity of different genres.
* Analyze total playtime across genres.
* Compare explicit and non-explicit tracks.
* Understand the relationship between genre and popularity.
* Create an easy-to-understand dashboard for data visualization.

---

## 📊 Dataset

The dataset contains information about Spotify tracks, including:

| Column              | Description                                 |
| ------------------- | ------------------------------------------- |
| `ID`                | Unique ID of the track                      |
| `Name`              | Name of the song                            |
| `Genre`             | Genre of the song                           |
| `Artists`           | Artist(s) associated with the song          |
| `Album`             | Album name                                  |
| `Popularity`        | Spotify popularity value                    |
| `Explicit`          | Whether the track contains explicit content |
| `Duration in Hours` | Duration of the track                       |

The dataset contains **192 tracks** across four genres:

* 🎸 Acoustic
* 🌍 Afrobeat
* 🎶 Alternative
* 🎵 Alt-Rock

---

## 🔍 Analysis Performed

### 1. Genre-wise Playtime

I analyzed the total duration of songs in each genre.

| Genre       | Total Playtime (Hours) |
| ----------- | ---------------------: |
| Acoustic    |                2624.47 |
| Afrobeat    |                2267.62 |
| Alternative |                2632.78 |
| Alt-Rock    |                2632.74 |

The overall playtime in the analyzed dataset is approximately **10,157.62 hours**.

---

### 2. Genre-wise Popularity

I also compared the total popularity values across genres.

| Genre       | Popularity |
| ----------- | ---------: |
| Acoustic    |       1256 |
| Afrobeat    |       1293 |
| Alternative |       1336 |
| Alt-Rock    |       1484 |

This comparison helps show how the popularity values are distributed across the different genres.

---

### 3. Explicit vs Non-Explicit Tracks

I analyzed the number of explicit and non-explicit tracks in the dataset.

| Track Type   | Number of Tracks |
| ------------ | ---------------: |

I also compared their total popularity:

| Track Type   | Total Popularity |

## 📈 Dashboard

I created a dashboard to present the analysis in a simple and visual format.

The dashboard focuses on:

* Genre-wise popularity
* Genre-wise playtime
* Explicit vs non-explicit tracks
* Overall Spotify data breakdown

The purpose of the dashboard is to make the analyzed data easier to understand without going through the raw dataset.

## 💡 Key Findings

From my analysis, I observed that:

* The dataset contains **192 tracks**.
* **Alt-Rock** has the highest total popularity among the analyzed genres.
* **Alternative** and **Alt-Rock** have very similar total playtime.
* Non-explicit tracks are much more numerous than explicit tracks.
* The total popularity of non-explicit tracks is higher than that of explicit tracks in this dataset.

These findings are based specifically on the dataset used in this project.
